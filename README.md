# F Pickup 3.0 (Minecraft 1.12.2 Forge)

Подбор предметов как в Rust:
- предметы НЕ подбираются, если просто пройти по ним (можно выключить в конфиге);
- наводишь прицел на предмет — вокруг него белая обводка, под прицелом надпись `[F] Поднять <предмет> xN`;
- жмёшь **F** — предмет поднимается. Клавишу можно поменять: Настройки → Управление → «Подбор предметов».

## Сборка через GitHub
1. Создай репозиторий на GitHub и залей туда ВСЁ содержимое этой папки (вместе со скрытой папкой `.github`).
2. Вкладка **Actions** → workflow **Build** запустится сам (или нажми *Run workflow*).
3. Когда сборка станет зелёной — открой её, внизу в **Artifacts** скачай `fpickup-1.12.2`.
4. В архиве возьми `fpickup-1.12.2-3.0.jar` (НЕ `-dev` и НЕ `-sources`) и положи в `mods`.
5. Удали из `mods` старый `fpickup-1.12.2-2.0.jar`.

## Конфиг
`config/fpickup.cfg`: disableAutoPickup, reach, showOutline, outlineWidth, showPrompt, promptOffsetY.

Мод нужен и на клиенте, и на сервере (в одиночной игре — просто в папке mods).
